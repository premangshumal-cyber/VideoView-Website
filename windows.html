VideoView for Windows.

A free local video and audio player with playlists, subtitle controls and a navy-and-teal desktop interface. Version 1.1.0 is a release candidate.

Requirements and compatibility

The published package contains an x64 Windows application built with WPF, .NET 10 and LibVLCSharp. It bundles .NET/Windows Desktop 10.0.12 and native x64 VLC 3.0.24. No separate native x86 or ARM64 build is supplied.

The project targets Windows 11 x64 and compatible Windows 10 x64 editions. Broad Windows 10 compatibility has not been established. Microsoft's .NET 10 support table limits Windows 10 support to specified LTSC/Enterprise editions. Check your exact Windows version against Microsoft's current .NET requirements. A supported runtime does not prove this release works on your machine.

The installer is designed for the current Windows user, with bundled runtime files. Clean-machine startup, real video and audio output, GPU behavior and installation still require native Windows testing.

How to install VideoView on Windows

  1. Use the official Windows download. The installer is VideoView-Setup.exe, version 1.1.0, 113,090,256 bytes.
  2. Open PowerShell in the folder containing the download and run:
    Get-FileHash .\VideoView-Setup.exe -Algorithm SHA256
    Compare the complete result with the published SHA-256 checksum. If it differs, do not run the file.
  3. Review the pre-release limitations. The installer is unsigned; an unknown-publisher prompt is possible. Do not disable Windows security protections to install it. Proceed only if you trust the source and are comfortable testing a pre-release.
  4. Close any existing VideoView session before upgrading. The installer is designed to use %LOCALAPPDATA%\Programs\VideoView, create Start Menu and uninstall entries, and offer optional Desktop/Open With integration. Those optional choices do not force a default-player change in the installer design.
  5. Open a local test file. Confirm the picture moves, audio is audible, and pause, seek and subtitles behave as expected. See the Windows acceptance checklist and report reproducible issues.

Using the portable edition

Download VideoView-Portable.zip (113,441,881 bytes), verify its checksum and extract all contents. Run VideoView/VideoView.exe in the extracted folder. Keep the adjacent runtime files and libvlc directory together; the EXE alone is not the complete application.

Portable describes the application folder. Settings, history and logs still use %LOCALAPPDATA%\VideoView; this is not an isolated USB profile. The documented installer preserves personal settings, playlists and media during normal uninstall, but native uninstall and upgrade behavior remain unverified.

Documented desktop features

  • Local video/audio playback through LibVLC, pause, seek and eleven speed settings from 0.25× to 4×.
  • Playlist import, search, sorting, multi-select, drag reordering and M3U/M3U8 saving.
  • External SRT, VTT, ASS and SSA subtitles, track selection, delays and appearance preferences.
  • Fullscreen, mini-player, aspect ratio, rotation and renderer preferences.
  • Keyboard controls, recent history and resume handling.

Read the feature overview, format limitations and keyboard shortcuts. URL streaming, DRM, casting, disc menus and timeline frame previews are outside this release's documented scope.

Release evidence and limits

Published documentation records successful compilation, package checks and 59 core assertions, plus narrower headless Linux playback diagnostics. These are not native Windows playback or installation tests. Review the quality status before using the release.
