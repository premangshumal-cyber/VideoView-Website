An open look at quality

What is verified. What comes next.

The application and installer were built successfully for Windows x64 from a Linux build environment. Test evidence covers core logic and limited headless Linux playback diagnostics; neither replaces a Windows acceptance run.

VERIFIED

Windows build and installer packaging

Release compiler results, PE architecture validation, bundled file inventory and installer-payload extraction checks are documented.

VERIFIED

59 core-logic assertions

Settings, playlists, history, sorting, imports, seeking logic and other production core behaviors passed the included tests.

NOT YET VERIFIED

Native Windows playback and UI

Visual rendering, sound output, GPU performance, input interactions, screen handling and subtitle appearance need direct Windows testing.

NOT YET VERIFIED

Clean Windows installation

First-run startup, install/uninstall, upgrade and normal-user verification remain open acceptance items.

Release candidate, not certified stable.

Do not describe this version as production-tested or clean-machine verified until the Windows acceptance checklist has been executed and signed off.
