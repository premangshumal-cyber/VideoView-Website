A simple explanation of what this website does, and how the software and third-party components are licensed.

Website privacy

This website is static HTML, CSS and JavaScript. The website code does not include analytics, advertising trackers, accounts, contact forms, or first-party tracking cookies. Your hosting provider may still process IP addresses, network requests and access logs to deliver the site; its privacy policy applies to that processing.

Software privacy

The VideoView release notes state that the application makes no telemetry or runtime downloads. Normal user-selected network file paths (for example, UNC shares) may use standard Windows network access. That software claim derives from the release materials and has not been independently verified on Windows.
