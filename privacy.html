Privacy & licenses.

A simple explanation of what this website does, and how the software and third-party components are licensed.

Website privacy

This website is static HTML, CSS and JavaScript. The website code does not include analytics, advertising trackers, accounts, contact forms, or first-party tracking cookies. Vercel hosts this site and may process IP addresses, request information and delivery logs. Downloads and public support discussions are hosted on GitHub. Those services process requests under their own policies: Vercel privacy policy and GitHub privacy statement.

Software privacy

The Windows 1.1.0 release notes state that the application makes no telemetry or runtime downloads. Android permissions and data handling have not been independently audited; this Windows statement should not be treated as an Android privacy guarantee. Normal user-selected network file paths (for example, UNC shares) may use standard Windows network access. That software claim derives from the release materials and has not been independently verified on Windows.

Licensing & open source

Original VideoView project code and icon assets: MIT license, © 2026 VideoView contributors. Dependencies—including .NET / WPF, LibVLCSharp, VLC, and NSIS—retain their respective license terms and attribution. The Windows original-code MIT license is reproduced from the published source archive. Android licensing and third-party notices require a separate release review. Windows source and third-party source bundles, notices and build recipes are provided in the download center.

Project publisher & contact

The official website and published release repository are maintained by premangshumal-cyber on GitHub. For website issues or software feedback, use the public issue tracker. Reports are public: remove personal information and private file paths before posting.
