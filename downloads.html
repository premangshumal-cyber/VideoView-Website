Need an answer?

Frequently asked questions.

Does VideoView work on Windows 10 and Windows 11?

It targets Windows 11 x64 and compatible Windows 10 editions; broad Windows 10 compatibility is not established. See requirements. This is a release candidate: build and package checks passed, but installation and graphical/audio playback on Windows hardware are not yet verified.

Do I need to install .NET or VLC separately?

The installer and portable package include the intended .NET/Windows Desktop runtime and VLC libraries. Clean-machine Windows startup and playback still need acceptance testing.

Why might Windows display an unknown-publisher message?

Version 1.1.0 is not code signed. Verify the download checksum and provenance before choosing to run it. A warning is not proof of malware, but it should be taken seriously.

Is the portable ZIP a single runnable EXE?

No. Extract all of its contents. The VideoView.exe within the extracted VideoView folder depends on nearby files and VLC plugins.

Will installing VideoView change my default media player?

The installer design does not force default-player takeover. Optional integration may appear during installation; native Windows behavior has not been verified yet.

Is VideoView open source?

The original VideoView project is MIT licensed. Third-party VLC, LibVLCSharp, runtime and installer components retain their own licenses. Get both source downloads above and review the bundled license notices.
